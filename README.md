# <teu-nome> Morphe patches — Tomato Animes

Patches para o [Morphe](https://morphe.software) para o app **Tomato Animes** (`com.tomatos.clientapp`).

> Não é afiliado ao projeto Morphe nem ao Tomato Animes. Este repo **não contém nenhum APK**, só código de patches.

## Patches

| Patch | O que faz |
|---|---|
| Cast via VLC | Troca o Google Cast do player por "abrir no VLC" (e daí fazer cast pelo próprio VLC) |

## Compatibilidade

| App | Package | Versão testada |
|---|---|---|
| Tomato Animes | `com.tomatos.clientapp` | 1.5.1 (101) |

## Adicionar ao Morphe

Depois do primeiro release, troca `USER/REPO`:

https://morphe.software/add-source?github=USER/REPO
